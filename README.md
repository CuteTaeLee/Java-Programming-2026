1. 클래스(Class)와 객체(Object)
클래스: 객체를 만들기 위한 설계도 (예: Rectangle 클래스).

객체(인스턴스): 설계도를 바탕으로 메모리에 실제 생성된 실체 (예: rect 변수가 가리키는 실제 사각형).

2. 생성자(Constructor) 오버로딩
같은 이름의 생성자를 매개변수의 개수나 타입을 다르게 하여 여러 개 정의하는 기술입니다.

사용자가 다양한 방식으로 객체를 초기화할 수 있도록 편의성을 제공합니다.

3. this()를 이용한 생성자 체이닝 (Constructor Chaining)
생성자 내부에서 자신의 다른 생성자를 호출할 때 사용합니다.

코드 중복을 방지하고 로직을 한곳으로 모을 수 있습니다.

주의사항: 반드시 생성자의 첫 번째 줄에서 호출해야 하며, 자기 자신을 순환 호출(Recursive invocation)하면 안 됩니다.
